# Demo script (3 min)
1. (15s) Problem: two PRs for one issue, both say tests pass. Which one is real?
2. (20s) Maintainer types `case 825` in the Switch room. Clerk posts the case file.
3. (40s) Examiner posts the claim ledger. Highlight a self-disclosed gap: PR #1436 reports hundreds of passing tests but states the live connection is follow-up work.
4. (30s) Skeptic (different provider) challenges one row; Examiner rebuts or downgrades it. Show the disagreement in the room.
5. (30s) UI board: side-by-side PRs, rows colored by status, every row links to evidence.
6. (25s) Maintainer approves the draft. Registrar posts to the sandbox fork. Show dry-run first, then live.
7. (20s) Close: what Switch gave us (room context, separate agents, approval in-room) and limitations.
Rule: say clearly what is recorded vs live.
